# Gym App Implementation Plan

> Executed inline in the same session (user approved the design and said start). No git commits unless the user asks.

**Goal:** Static Arabic RTL PWA that turns the 12-week plan into a daily tool (menu, workouts with videos, tracking, calendar reminders) for any program length.

**Architecture:** No-build ES modules. Pure engine modules under `js/engine/` (unit-tested with `node --test`), data under `js/data/`, DOM rendering under `js/ui/`, one `localStorage` state object.

**Tech Stack:** HTML, CSS, vanilla JS (ES2022 modules), Node 24 test runner, service worker, Google Calendar template links + ICS.

## Global Constraints
- All paths relative (GitHub Pages sub-path). `start_url: "./"`.
- No personal data in source. First-run onboarding collects it.
- UI language Arabic (Egyptian), `dir="rtl"`; numbers Latin digits.
- Engine rules exactly as in the spec "Engine rules" and "Program" sections.

## Tasks

### Task 1: Engine — dates, bodycomp, energy
Files: `js/engine/dates.js`, `js/engine/bodycomp.js`, `js/engine/energy.js`, `tests/engine.test.js`, `package.json`
Produces:
- `toISO(d: Date): string`, `fromISO(s): Date`, `addDays(iso, n): string`, `diffDays(a, b): number` (b − a), `weekday(iso): 0..6` (0 = Sunday), `weekNo(startIso, iso): number` (1-based; ≤ 0 before start)
- `navyMale({waist, neck, height})`, `rfmMale({height, waist})`, `armyMale({weightKg, waist})`, `estimateBodyFat({weightKg, height, waist, neck}) → {navy, rfm, army, bf, lbm, fatMass}`
- `mifflinMale({weightKg, height, age})`, `katch(lbm)`, `bmr({weightKg, height, age, bf, lbm})`, `deficitPct(bf)`, `computeTargets({tdee, bf, lbm, weightKg, mode, kcalOffset}) → {kcal, protein, fat, carbs, deficit}`, `movingAverage(weights, endIso, days)`, `trendTdee({weights, intakeFor, endIso, windowDays})`, `advice({weights, waists, endIso, weekNumber})`
Tests: reference example (95 kg, 175 cm, 30 y, neck 40, waist 105) → Navy 29.1, RFM 30.7, Army 30.2, BF 29.9, Mifflin 1899, targets at PAL 1.375 → 2100 kcal, protein 175; trend TDEE example (2,200 intake, −2.1 kg / 21 d → 2,970).

### Task 2: Engine — program
Files: `js/engine/program.js`, `tests/program.test.js`
Produces: `SESSION_BY_WEEKDAY`, `buildProgram(totalWeeks) → Week[]` where `Week = {week, phase: 'ramp'|'build'|'push'|'deload'|'test', sets, rir, isoRir, extraSetFirst, calories: 'deficit'|'maintenance'}`, `stepsTarget(week)`, `dayPlan({startIso, totalWeeks, iso}) → {weekNumber, inProgram, week, sessionKey}`
Tests: 12 weeks → ramp 1–2, build 3–6, deload 7, push 8–11, test 12; 24 weeks has deloads at 7, 12, 17, 22 and test at 24; Saturday → pushA, Friday → rest.

### Task 3: Data + engine — foods, menus, scaling, swaps
Files: `js/data/foods.js`, `js/data/menus.js`, `js/engine/menu.js`, `tests/menu.test.js`
Produces: `FOODS: Record<id, {name, kcal, p, c, f, group, unit?, unitName?}>`, `MENUS: DayTemplate[7]` (index = JS weekday), `totals(items)`, `scaleDay(template, targets)`, `equivalentGrams(fromId, grams, toId)`, `swapCandidates(foodId)`, `applySwaps(day, swaps)`, `dayIntake(dayLog, day)`
Tests: every menu food id exists; every day scaled to targets {1800/150, 2200/185, 2700/185, 2800/210} lands within ±75 kcal and ±8 g protein; swap chicken→tuna keeps protein within 1 g.

### Task 4: Engine — reminders
Files: `js/engine/reminders.js`, `tests/reminders.test.js`
Produces: `gcalLink(event)`, `reminderEvents({startIso, endIso, mealTimes, sessionNames})`, `toICS(events)`
Tests: link contains `action=TEMPLATE`, `ctz=Africa%2FCairo`, encoded `RRULE:FREQ=DAILY;UNTIL=…`; ICS has VCALENDAR/VEVENT/RRULE lines and CRLF.

### Task 5: Exercises + videos data
Files: `js/data/exercises.js` (+ `research/videos.json` from the video research)
Produces: `EXERCISES: Record<key, {name, ar, reps, lower, cues, alt[], video?, backup?}>`, `SESSIONS: Record<sessionKey, {name, ar, exercises: key[]}>`
Test: every session exercise key exists; every video id is 11 chars.

### Task 6: Store + UI + PWA
Files: `index.html`, `css/app.css`, `js/app.js`, `js/store.js`, `js/ui/*.js`, `manifest.webmanifest`, `sw.js`, `icons/*`
Behaviour per spec: onboarding → tabs (اليوم، الأكل، التمرين، التقدم، الإعدادات); export/import; reminders screen.
Verification: serve locally, run through every tab at 375×812, no console errors.
