# خطتي — أبليكيشن التنشيف وبناء العضل

ويب أبليكيشن (PWA) بالعربي: منيو 7 أيام بالأكل المصري، وبرنامج Push/Pull/Legs بأي مدة، وفيديوهات تكنيك، ومتابعة الوزن والمقاسات، وتذكيرات على Google Calendar.

- بياناتك الشخصية مش في الكود. بتدخلها أول مرة تفتحه، وبتتخزن على الموبايل بس.
- الحسابات (الدهون، السعرات، المنيو، البرنامج، التذكيرات) في `js/engine/` ومعاها اختبارات.

## تشغيل محلي
```bash
python3 tools/devserver.py 8765
```
وافتح http://localhost:8765

## الاختبارات
```bash
node --test
```

## الرفع على GitHub Pages
كل الروابط نسبية، فينفع يترفع زي ما هو على أي مسار (`https://<user>.github.io/<repo>/`).
بعد أي تعديل، غيّر `VERSION` في `sw.js` عشان الموبايلات تاخد النسخة الجديدة.

## المصادر
- أرقام الأكل: USDA FoodData Central، وبيانات معملية مصرية، ووصفات محسوبة.
- الفيديوهات: `research/videos.json` (كل ID اتأكد إنه شغال ومسموح يتعرض جوه مواقع تانية).
